# EV Performance Analysis Dashboard

## 🚗 Project Overview

Electric Vehicles (EVs) are transforming the transportation industry, making it increasingly important to understand the factors that influence their performance, charging efficiency, and energy consumption.

This project analyzes EV operational data to uncover patterns affecting vehicle efficiency, charging behavior, battery performance, and energy utilization. Using Python for data preprocessing and Power BI for visualization, the project delivers an interactive dashboard that helps stakeholders make informed, data-driven decisions.

---

# 🎯 Business Problem

Organizations managing electric vehicles need answers to questions such as:

- Which factors affect EV efficiency?
- How does charging duration vary across vehicle types?
- Does weather influence range utilization?
- Which regions consume more energy?
- What operational trends can improve EV performance?

This dashboard addresses these questions through interactive visualizations and business-focused analytics.
